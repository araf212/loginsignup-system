# 🔐 Login & Signup System

A modern Login & Registration System developed using PHP, MySQL, HTML, and CSS. This project demonstrates user authentication with secure password hashing, session management, and a responsive user interface.

---

## 📸 Project Preview

### Signup Page
- User Registration
- Duplicate Email Validation
- Password Hashing

### Login Page
- Secure Login
- Session Authentication
- Password Verification

### Dashboard
- Welcome Page
- User Information
- Logout Functionality

---

## 🚀 Features

- ✅ User Registration
- ✅ User Login
- ✅ User Logout
- ✅ Session Management
- ✅ Password Hashing (`password_hash()`)
- ✅ Password Verification (`password_verify()`)
- ✅ Duplicate Email Validation
- ✅ Responsive User Interface
- ✅ MySQL Database Integration
- ✅ SQL Injection Protection (Prepared Statements)

## ⚙️ Installation Guide

### Step 1

Clone the repository

```bash
git clone https://github.com/araf212/loginsignup-system.git
```

---

### Step 2

Move the project folder into

```
C:\xampp\htdocs\
```

---

### Step 3

Start

- Apache
- MySQL

using XAMPP.

---

### Step 4

Open

```
http://localhost/phpmyadmin
```

---

### Step 5

Create a database named

```
loginsignup_system
```

---

### Step 6

Import

```
loginsignup_system.sql
```

---

### Step 7

Run the project

```
http://localhost/loginsignup
```
