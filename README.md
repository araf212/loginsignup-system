# Login Signup System

## Technologies

- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Database

Database Name:

loginsignup_system

Import File:

loginsignup_system.sql

## Installation

1. Copy the project folder into `xampp/htdocs`.
2. Start Apache and MySQL in XAMPP.
3. Open phpMyAdmin.
4. Create a database named `loginsignup_system`.
5. Import `loginsignup_system.sql`.
6. Visit `http://localhost/loginsignup`.
